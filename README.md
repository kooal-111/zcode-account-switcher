# Z·SWITCH RU — переключатель аккаунтов ZCode

Графический инструмент для **быстрого переключения между несколькими аккаунтами ZCode** без повторного входа: проекты, сессии и настройки остаются нетронутыми — меняется только учётная запись.

> ## 🇷🇺 Полностью на русском языке
> Интерфейс **по умолчанию запускается на русском** — язык подхватывается автоматически из настроек системы. Также доступны 中文 и English (переключение в настройках приложения). Русский есть везде: в главном окне, настройках, окне капчи, сообщениях об ошибках и CLI.

Основано на [pjpv/zcode-switch](https://github.com/pjpv/zcode-switch) (v1.7.0-beta.1, MIT) с добавлением русского интерфейса и ряда доработок (см. [Отличия от апстрима](#отличия-от-апстрима)).

## Возможности

- **Сохранение / переключение аккаунтов** — снимок `credentials + config` на аккаунт, атомарная замена. Перед каждым переключением текущий вход сохраняется автоматически, «потерять» аккаунт нельзя.
- **Добавление аккаунтов** — OAuth-вход прямо из инструмента (z.ai / BigModel), не затрагивая текущую учётную запись.
- **Показ квот** — остаток тарифа и время сброса прямо в списке аккаунтов.
- **Получение промо-пакетов** — разовое и **автоматическое** (по расписанию, с прозрачной капчей Aliyun — той же, что использует сам клиент ZCode).
- **Проверка аккаунта после переключения** — инструмент сразу опрашивает сервер и предупредит, если у аккаунта истёк вход или нет доступных тарифов.
- **Шифрованный экспорт/импорт** — перенос всех аккаунтов между компьютерами в файле `.zsb` (PBKDF2 100k + AES-256-GCM, пароль задаёте вы).
- **Поддержка кастомной папки данных ZCode** (`dataBaseDir`).
- **Трей, автозапуск, CLI-автоматизация.**
- **🇷🇺 Русский / 中文 / English** — переключение на лету.

## Установка

1. Зайдите в [Releases](https://github.com/kooal-111/zcode-account-switcher/releases) и скачайте `zcode-switch_*_x64-setup.exe` (установщик) или `*_portable.exe` (без установки).
2. Windows SmartScreen предупредит о неподписанном файле — нажмите **«Подробнее» → «Выполнить в любом случае»**. Подпись отсутствует, потому что сборки делаются без покупки сертификата; сверяйте SHA-256 из файла `checksums-sha256.txt` в релизе.
3. Требования: Windows 10/11 x64 и установленный клиент ZCode.

## Быстрый старт

1. **Сохранить вход** — текущий логин ZCode запишется в библиотеку как первый аккаунт.
2. **Добавить** — войти в другой аккаунт z.ai / BigModel в открывшемся окне (текущий вход не затрагивается).
3. **Переключить** — ZCode закроется и запустится под выбранной учётной записью. Несохранённый вход перед этим автоматически уедет в библиотеку.

Пара замечаний:

- **Горячее переключение** (настройки) меняет аккаунт без перезапуска клиента — быстрее, но открытые сессии продолжат работать со старым аккаунтом до перезапуска. По умолчанию выключено.
- **Автополучение** (настройки) раз в 10 минут проверяет доступные промо-пакеты и забирает их сам; если нужна ручная капча — инструмент сообщит.
- Данные хранятся локально: аккаунты — в `~\.zcode-switch\`, состояние ZCode — в `~\.zcode\v2\`. Никуда, кроме официальных серверов z.ai/BigModel, ничего не отправляется.

## CLI

```
zcode-switch.exe --cli state|list
zcode-switch.exe --cli quota [--id <id>]
zcode-switch.exe --cli capture [--name Имя]
zcode-switch.exe --cli switch --id <id> [--force] [--restart|--no-restart] [--hot <bool>|--no-hot]
zcode-switch.exe --cli export --id <id> --out файл.zsb
zcode-switch.exe --cli import --file файл.zsb
zcode-switch.exe --cli rename|delete|update|behavior|setpath|launch|kill
```

Пароль для `export`/`import` передаётся через переменную окружения `ZSW_PASSWORD` (не попадает в историю команд) или параметром `--password`.

## Безопасность

- Все данные — только локально; телеметрии нет, удалённого хранения нет.
- Снимки аккаунтов лежат в `~\.zcode-switch\accounts\` в открытом виде **на вашем диске** — как и оригинальный `credentials.json` клиента ZCode; экспортный файл `.zsb` всегда зашифрован паролем.
- Ключи шифрования экспорта — PBKDF2-HMAC-SHA256 (100 000 итераций) + AES-256-GCM со случайными salt/nonce.
- Сетевые обращения: только официальные эндпоинты z.ai / BigModel и капча Aliyun (тот же SDK, что в клиенте ZCode).
- Исходный код открыт — собирайте сами, если не доверяете готовым бинарникам.

## Отличия от апстрима

- 🇷🇺 Полноценный русский интерфейс (в апстриме только 中文/English).
- `deviceMid` пишется в оба места, где его хранит современный ZCode (3.14+): `telemetry-state.json` **и** `onboarding-record.json` — идентичность устройства корректно следует за аккаунтом.
- Выбор подключения семьи провайдеров (`modelProviderFamilySelectedKeys` и связанные ключи из `setting.json`) сохраняется в снимок аккаунта и восстанавливается при переключении.
- Версия клиента в заголовках API берётся из реестра (fallback 3.14.4) вместо устаревшей константы.
- Восстановлен юнит-тест-сьют (апстрим удалил тесты в 1.7.0-beta.1).

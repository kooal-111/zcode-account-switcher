# Changelog

## 1.7.0-beta.2 — 2026-11-02

Совместимость: Z Code 3.14–3.17.x (проверено на 3.17.1).

### Исправлено
- **Клеймы снова видны без ручных действий**: preview доступных пакетов запускается
  автоматически при старте, после сохранения/добавления/переключения аккаунта, после
  получения пакета и по TTL (5 минут). Раньше плашка появлялась только после
  «Обновить права» или авто-получения.
- **Состояния клеймов различаются**: «не проверено» / «проверяем» / «есть пакет» /
  «нет пакетов» / «ошибка + повторить» / «данные обновляются». Раньше «не проверено»
  и «пусто» выглядели одинаково.
- Очередь preview: максимум 2 запроса одновременно с паузой 350 мс — меньше 429
  при большом числе аккаунтов; повторные ответы с устаревшим requestId игнорируются.
- CAPTCHA: таймаут и ретраи загрузки SDK, таймаут отправки без небезопасной
  повторной отправки claim, защита от двойной отправки, закрытие окна отменяет
  ровно свою попытку claim.
  Убран безусловный `--no-proxy-server` — системный/настроенный прокси больше не
  отключается (важно для капчи и входа за прокси).
- Активационная телеметрия — не чаще раза в сутки на (аккаунт, хэш deviceMid,
  версия клиента); передаётся реальное разрешение экрана и `ui_mode: code`.
- Коды ответов сервера принимаются и числом, и строкой (`0`/`"0"`/`1001`/`"1001"`).
- Блокирующие сетевые вызовы вынесены из async-команд Tauri в `spawn_blocking`
  — интерфейс больше не подвисает на запросах.
- Захватывающая капчу попытка атомарно резервируется и защищена claim_id:
  параллельный старт, чужую или отменённую капчу сдать нельзя; сверхбыстрый
  результат не теряется между стартом и установкой ожидания во фронтенде.

### Изменено
- Структурированные гранты: строки с китайскими периодами больше не формируются
  в Rust — локализация полностью во фронтенде.
- Зависимости: Tauri 2.12.x, Vite 8.3.5 (rolldown/oxc), Node >= 20.19.
  npm audit: 0 уязвимостей (было 2 high + 1 moderate).
- Качество: clippy `-D warnings` чист, cargo fmt, vitest (19 тестов),
  Playwright UI-тесты (9 сценариев: размеры 520×640/680×820/900×700, локали,
  зум 125/150%, клавиатура), cargo test — 20 тестов, фикстуры API без реальных данных.
- CI: полный набор проверок (i18n, vitest, build, npm audit, fmt, clippy, cargo test,
  cargo audit, Playwright); логи падений — в artifacts, а не в ветку.

### Безопасность
- deviceMid в кэше активаций только как sha256-ключ; токены в логах/диагностике
  отсутствуют; `ZSW_DUMP_PREVIEW=1` печатает только код ответа и массив планов.
